This project focuses on autonomous navigation for a TurtleBot 3 through an indoor obstacle course using custom Nav2 plugins in ROS 2. In this work, we implemented and compared three planning approaches: raw A* on an octile grid, A* with line-of-sight waypoint skipping as post-processing, and Theta* as an any-angle planner.

We paired these planners with Savitzky–Golay smoothing and a Regulated Pure Pursuit controller. The controller includes curvature-based speed reduction, obstacle-proximity scaling, adaptive lookahead, and separate goal alignment logic to handle final orientation.

The system was developed in ROS 2 Jazzy using C++17 and tested in both Gazebo and on physical hardware. During testing, we troubleshooted issues such as SLAM drift, network-induced stoppages, and controller instability. We also explored simple methods for reducing velocity jerk, including rate limiting and first-order filtering, to improve real-world behaviour.

**Software stack:** ROS 2 Jazzy, C++17, Nav2 plugins, Gazebo, TurtleBot 3, Foxglove.
